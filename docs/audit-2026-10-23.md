## Original ranked list (b315)
### A. Correctness (verdict-affecting)
1. **b313 incomplete** — six id-based CSS gates survive (`#hsiPanel #decisionPanel #airPanel #icePanel #vfrPanel #routePanel` hidden outside airplane/xc; `.no-airplane` hides thermals in airplane). `renderDecision` also blanks itself outside airplane/xc. Fix: delete the six rules, scope `.no-airplane:not(.panel)`, make `renderDecision` render a note.
2. **Stale auxiliary panels on site change** — `fetchOutlook`, `fetchTetherOutlook`, `fetchConvDeep`, `fetchConvArea` null their state on failure but never re-render, and `applyForecast` renders with the previous fetch's aux data first. Tag datasets with `{lat,lon}`; render "unavailable" on every failure path.
3. **`restoreCache` ignores site/model** — cached forecast restored for a different lat/lon. Compare `c.lat/lon/model`.
4. **Ensemble `forecast_days=2`** vs main 3 → day-3 targets kill Best Windows (`fetchEnsemble`, `fetchConvEnsemble`).
5. **Ceiling: four implementations, VV disagreement** — `parseMetarLine`/`tafCloud` count VV as ceiling; `fetchNWS`/`fetchMetarX` do not → a VV002 ob via NWS JSON reads as VFR. One `ceilingFromLayers()`.
6. **Model-cloud ceiling implemented four times** with thresholds 50% vs 13% (balloon) — consolidate on `lowestCloudAGL(h, cover)`.
7. **Icing: no freezing-precip/SLD check** — weather codes 56/57/66/67 never referenced. Add hard flag + warm-nose check (AC 91-74B).
8. **`fetchConvEnsemble`** mixes UTC epoch with local-parsed timestamps when `tISO` is null (off by device offset).
9. **Fog "High" unreachable** — RH≥95 gate contradicts the 1.5 °C spread (≈90% RH). Drop RH clause or use ≥90.
10. **`detectInversion`** labels any warmer level in lowest 6 kft "surface-based" even when the profile cools first.
11. **Turbulence shear band** applies 4/6/10 kt/kft bins to the 229-ft 10→80 m layer → "Strong" from a 3 kt friction difference. Skip shear band below ~300 ft AGL.
12. **`severeKin`** `has06` gate at 18,000 ft vs 6,000 m (19,685 ft) evaluation — slight under-report.
13. **`renderSun`** labels UTC as "device-local"; `new Date(w)` parses datetime-local as local before `getUTCDate()` (solar date can roll a day).
14. **`fetchSoft`** 72 h precip sums 3 past days + today's forecast day.
15. **Manual/emergency** blank elevation → sea-level DA; prefill from `omElev`.

### B. Regulatory text (user-facing)
16. 61.57(**c**) cited for night passenger currency — should be 61.57(b); add same category/class + sole manipulator (balloon landings ≠ Archer).
17. "position/anti-collision lights sunset→sunrise (91.209)" — only position lights are sunset–sunrise (91.209(a)); anticollision whenever installed (91.209(b)); night-VFR equipment 91.205(c) (powered aircraft only).
18. Dawn window starts 15 min before sunrise with no "position lights required until sunrise" note.
19. "Day VFR ops run sunrise→sunset" — not a regulatory definition; 91.155 day/night split keys on 1.1 civil-twilight night.
20. Three "night" clocks coexist unlabeled: ribbon/route use geometric solar elevation (0°/−6°); ensemble windows & outlook use Open-Meteo `is_day` (sunrise–sunset); daylight panel uses 90.833°/96°. Standardise on one `sunState(t)` → {day, civilTwilight, night, lightsRequired, paxCurrencyNight}.
21. Route "dusk" tag applied to morning twilight.
22. "500 ft VFR clearance" presented as universal — Class G ≤1,200 AGL day is clear-of-clouds + 1 SM; label as personal buffer.
23. "AIRMET Tango/Zulu" → G-AIRMET (CONUS text AIRMETs retired 27 Jan 2025, SCN 24-92).
24. Ceiling definition omits VV into obscuration (1.1).
25. Handbook sub-section cites (§3.4.2.14, §8.4.1.5, §10.7.2, Table 24-6) unverified against 28B TOC.

### C. Robustness / performance
26. Personal-minimum inputs wired twice (lines ~6536 and ~7693) → heavy renderers run 2–3× per keystroke, undebounced; `verdict()` ≥4× and `renderConvective()` ≥6× per fetch. Single debounced `minsRerender()`; remove `verdict()` from `renderTrends`.
27. Consensus `one()` returns null identically for HTTP error / timeout / no-hour → footnote misattributes. Return a reason.
28. Fetches with no timeout: airports/runways CSV, RainViewer index, zippopotam, geocoder.
29. HTTP 429 not retried in `fetchJSON` (likely with 14 consensus calls + 49–121-pt grids).
30. Duplicate fetches per cycle: `/observations/latest` ×2 (different ceiling logic), `/points` ×2, `/alerts/active` ×2 (point vs area), overlapping Open-Meteo point calls (OM 3 d, outlook 7 d, tether outlook 7 d, convDeep 3 d).
31. `fetchStations` `Promise.all` → one failing station fails all.
32. Visual-view modal clones `innerHTML` → all handlers inert (tether strips, pressure sliders, play, drag-rotate, buttons); canvas copies blank. Move the live node instead of cloning. Ten panels have neither `.sect-sum` nor an SVG → empty tiles.
33. Dead windfield cluster (`renderWindfield`, `wfDraw`, `WF_LEVELS`, `#wgGrid/#wgCtrl/#wfPlot` never exist) and unused globals `colAz, wfTimer, wfIdx, wfRows`.
34. Personal-minimum reads scattered across 14 functions with `||default` (a typed 0 becomes the default); `thVis/thCeil` NaN silently disables the check. One `readMins()`.
35. RH-from-dewpoint inlined ×3; flight-category colours in two palettes.
36. `zc_apts`/`zc_rwys` cache whole CSVs with no TTL/version.
